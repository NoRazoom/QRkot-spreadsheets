# QRkot-spreadsheets

Приветствую в ультра-мега-клевом приложении QRkot!

В последней версии были добавлены составление отчета, содержащего все закрытые проекты: для каждого - время закрытия проекта и его описание. Функция доступна только для суперпользователей.

Документацию к проекту вы так же можете найти по ссылке [127.0.0.1:8000/docs#](http://127.0.0.1:8000/docs#/) при развернутом локально проекте. 


Использованные технологии: python, fastapi, fastapiUsers, pandas, xlsxwriter, ЯндексДиск АПИ.
